## [0.1.0] - Unreleased

### Added

- `@zutools/core` with framework-independent Base64, CSV, JSON, text, timestamp,
  image, image metadata and Word Counter engines.
- `@zutools/react` with the complete catalogue and an individual Word
  Counter entry.
- Compiled ESM, TypeScript declarations, source maps and separately exported
  CSS.
- A local-first catalogue containing 11 executable browser tools.
- Tarball consumer tests for JavaScript, React and strict TypeScript projects.
- Runnable Vanilla JavaScript and React examples built from package tarballs.
- Bundle-size regression checks, dependency license validation and continuous
  integration on supported Node.js LTS versions.
